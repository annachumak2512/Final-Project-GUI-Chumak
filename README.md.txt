AgroAssistant Pro — Робоче місце агронома

Програма з графічним інтерфейсом (GUI) на базі Tkinter для автоматизації обліку полів та розрахунків у фермерському господарстві.

🚀 Основний функціонал:
 🗺️ Інтерактивна карта полів (6 ділянок) із колірним відображенням культур.
 📊 Модуль аналітики: автоматичний підрахунок загальної площі господарства та площ під кожну культуру окремо в реальному часі.
 💾 Збереження та завантаження: можливість підписувати та зберігати різні версії карт у форматі ".json", а також завантажувати їх назад у програму.
 🔄 Швидке скидання: кнопка очищення всієї карти під оранку в один клік на початку сезону.
 🧮 Агро-калькулятори: розрахунок необхідної кількості добрив на площу та норми висіву насіння (кг/га) за агрономічною формулою.
 ☀️ Погодний контроль: інтерактивна таблиця-довідник оптимальних температур та швидкості вітру для проведення польових робіт.
